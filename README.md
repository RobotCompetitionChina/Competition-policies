## 文件状态

制度文件应当标明以下状态之一：现行、试行、修订中、已废止或已被替代。

## 版本管理

正式发布的制度文件原则上不直接覆盖。修订后应上传新版本，并将旧版本移动到历史文件目录或明确标注为“已被替代”。

## 版权说明

相关文件版权归原发布单位所有。本仓库主要用于资料整理、公开查阅和历史存档。
